## Key Takeaways

- **Stack (LIFO)**: Last element added is first to be removed.
- **Monotonic Stack**: Efficiently find next/previous greater/smaller.
- **Use Stack for**: Parentheses matching, reversing, expression evaluation, DFS.
- **Space Optimization**: Always consider auxiliary space complexity.
- **Edge cases**: Empty stack, single element, duplicates.
- **Stack vs Recursion**: Often more efficient and avoids stack overflow.
- **Design Patterns**: Practice custom stack implementations for interviews.
