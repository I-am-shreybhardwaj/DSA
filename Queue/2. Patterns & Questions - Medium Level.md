## Learning Roadmap

1. Strengthen your **easy Queue patterns** if not mastered.
2. Start with **complex BFS patterns**.
3. Progress to **multi-source BFS** problems.
4. Explore **deque advanced operations** and sliding window.
5. Attempt **topological sort with queue** (Kahn's algorithm).
6. Solve **shortest path and graph traversal** problems.
7. Learn **queue design advanced** patterns.
8. Practice **level order with constraints**.
9. Master **complex constraints and obstacles**.
10. Consolidate with **medium-level classic problems**.

---

## Key Insights

- **BFS**: Most efficient for shortest path in unweighted graphs.
- **Deque for Window**: Better than regular queue for max/min queries.
- **Multi-source BFS**: Initialize all sources for efficient exploration.
- **Topological Sort**: Use Kahn's algorithm with queue.
- **0-1 BFS**: For graphs with weights 0 and 1.
- **Space Optimization**: Queue-based algorithms are memory-friendly.
- **State Representation**: Carefully design state for BFS problems.
