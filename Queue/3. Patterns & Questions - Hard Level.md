## Learning Roadmap

1. Start with **medium Queue patterns** if not already mastered.
2. Focus on **advanced BFS algorithms** (bi-directional, 0-1).
3. Attempt **complex state space search** problems.
4. Tackle **shortest path with multiple constraints**.
5. Master **deque with DP optimization**.
6. Solve **advanced topological sort** problems.
7. Learn **advanced queue design patterns**.
8. Explore **complex graph traversal** algorithms.
9. Study **sliding window optimization with deque**.
10. Consolidate with **hard classic problems** for interviews and competitive programming.

## Advanced Techniques

- **Bi-directional BFS**: Meet in the middle for faster search.
- **0-1 BFS**: For graphs with weights 0 and 1.
- **Deque Optimization**: Better than priority queue for specific constraints.
- **State Compression**: Use bitmask for efficient state representation.
- **Multi-source BFS**: Parallel exploration for efficiency.
- **Topological Sort**: Kahn's algorithm with queue for cycle detection.
- **DP with Deque**: Combine DP with monotonic deque optimization.

---

## Key Takeaways

- **Queue/BFS** is fundamental for hard-level graph and state space problems.
- **Deque** is powerful for sliding window and DP optimization.
- **Multi-source BFS**: Essential for constraint-based search.
- **State representation**: Critical for efficient state space search.
- **Constraint handling**: Carefully manage obstacles and limitations.
- Practice both **forward and backward** search approaches.
- Always consider **space and time complexity** trade-offs.
