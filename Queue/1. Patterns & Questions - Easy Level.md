## Learning Roadmap

1. Start with **basic queue operations** and understanding FIFO principle.
2. Practice **level-order traversal** in trees.
3. Learn **BFS basics** for graph traversal.
4. Master **circular queue** design and implementation.
5. Solve **multi-source BFS** problems.
6. Practice **deque operations** for two-ended access.
7. Learn **queue design and implementation** variations.
8. Apply **BFS to various problems** (islands, distance, etc).
9. Handle **queue with constraints** problems.
10. Build confidence with **miscellaneous classic problems**.

## Key Takeaways

- **Queue (FIFO)**: First element added is first to be removed.
- **Deque**: Supports operations at both ends.
- **Use Queue for**: BFS, level-order traversal, sequential processing.
- **Multi-source BFS**: Initialize all sources in queue at once.
- **Space Optimization**: Always consider auxiliary space complexity.
- **Edge cases**: Empty queue, single element, boundary cells.
- **Distance Tracking**: Mark visited while enqueueing to avoid revisits.
