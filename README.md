## 💡 Key Patterns Overview

### Array Patterns You'll Master:

- **Sliding Window**: Find subarrays, substring problems
- **Two Pointers**: Sorted arrays, pair problems
- **Prefix Sum**: Range sum, subarray queries
- **Hashing**: Frequency, existence, counting
- **Binary Search**: Search, boundaries, rotation
- **Greedy**: Optimal selection, interval problems
- **DP**: Optimal substructure, state transitions
- **Monotonic Stack**: Next greater/smaller, span problems

### Stack Patterns You'll Master:

- **Basic Operations**: Push, pop operations, LIFO principle
- **Balanced Parentheses**: Bracket matching, validation
- **Monotonic Stack**: Next greater/smaller, span problems
- **Expression Evaluation**: Postfix, infix, operator precedence
- **String Processing**: Adjacent duplicates, decoding, reversal
- **Min/Max Stack**: Efficient range minimum/maximum
- **Histogram Problems**: Largest rectangle, skyline
- **DFS Alternative**: Stack-based iteration instead of recursion

### Queue Patterns You'll Master:

- **Basic Operations**: Enqueue, dequeue, FIFO principle
- **BFS/Level Order**: Tree traversal, graph exploration
- **Multi-source BFS**: Parallel exploration from multiple sources
- **Shortest Path**: Unweighted graphs, 0-1 BFS
- **Deque**: Two-ended access, sliding window optimization
- **Topological Sort**: Kahn's algorithm, dependency resolution
- **Circular Queue**: Fixed-size queue with wraparound
- **State Space Search**: Complex state exploration

## 🔧 Important Techniques

### Array Techniques:
- Prefix sum for range queries
- Two pointers for optimization
- Sliding window for efficiency
- Sorting for grouping
- Binary search for O(log n) solutions
- Greedy when local optimal = global optimal
- DP for complex subproblems

### LinkedList Techniques:
- Dummy nodes for clean code
- Fast/slow pointer for middle/cycle
- Floyd's algorithm for cycle detection
- Recursion (carefully) for elegant solutions
- Merge sort for LinkedList sorting
- Reversal for rearrangement
- Hash map for O(1) lookups
