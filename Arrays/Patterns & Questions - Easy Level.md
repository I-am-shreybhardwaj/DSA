## Sliding Window

Used for problems involving **subarrays** and **contiguous ranges**.

**Patterns:**
- Fixed-size window (k)
- Variable-size window
- Longest/shortest subarray

## Learning Roadmap

1. Start with **easy array problems** (Two Pointers, Prefix Sum).  
2. Gradually practice **sliding window and hashing**.  
3. Move to **in-place modifications, sorting, greedy**.  
4. Finish with **matrix problems, Kadane’s, monotonic stack**.  
5. Try **medium and hard problems** after mastering patterns.
