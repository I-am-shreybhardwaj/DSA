## Learning Roadmap

1. Start with **medium array patterns** if not already mastered.  
2. Focus on **sliding window, two pointers, and hashing variants** in complex scenarios.  
3. Attempt **matrix DP, monotonic stacks, and prefix sum variants**.  
4. Tackle **binary search on answer and advanced greedy problems**.  
5. Master **2D dynamic programming and state compression**.
6. Explore **advanced string patterns and bit manipulation**.
7. Learn **segment trees and advanced data structures**.
8. Consolidate with **hard classic problems** for interviews and competitive programming.

---

## Advanced Techniques

- **Binary Search on Answer**: Instead of finding exact value, search for feasibility.
- **Greedy with Proof**: Always prove why greedy works.
- **DP Optimization**: Use techniques like Convex Hull Trick, CHT.
- **Bit DP**: Combine bitmask with DP for subset problems.
- **Segment Trees**: Essential for range query problems.
